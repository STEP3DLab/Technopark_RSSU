# Источники изображений

Фотографии в блоке «Реальные кейсы X.Lab» взяты из публичного Telegram-канала [STEP 3D Lab / X.Lab](https://t.me/STEP_3D_Lab) и оптимизированы в WebP для сайта.

## Награда премии СТД

- Исходная публикация: https://t.me/STEP_3D_Lab/539
- Файлы на сайте: `award-final.webp`, `award-stage.webp`
- Подпись на сайте: «Фото и кейс: X.Lab»

## Светильники для мюзикла «Последняя сказка»

- Исходная публикация: https://t.me/STEP_3D_Lab/530
- Файлы на сайте: `theater-cad.webp`, `theater-making.webp`, `theater-installation.webp`, `theater-final.webp`
- Подпись и ссылка на публикацию размещены внутри кейса.

При публикации на основном домене рекомендуется сохранить видимую атрибуцию и ссылки на исходные посты.
