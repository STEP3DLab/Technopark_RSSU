# Страница СКБ Технопарка РГСУ

Production-ready фронтенд страницы Студенческого конструкторского бюро в актуальной стилистике основного сайта РГСУ.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8080
```

После этого откройте `http://localhost:8080/rgsu-skb/`, если сервер запущен из родительской папки проекта.

## Что работает

- адаптивная навигация;
- отдельный сценарий обращения студента за практической частью курсовой или ВКР;
- примеры учебных результатов, распределение ответственности и FAQ;
- интерактивная карта проектной среды, схема лабораторий и инфографика этапов;
- HUD-визуализации проектов, индикатор прокрутки и подсветка активного раздела;
- карточки лабораторий с подробной информацией;
- две версии формы: для организации и для студента;
- проверка формы и размера вложения до 4 МБ;
- отправка формы через настраиваемый API с резервным сценарием через e-mail;
- поисковые метаданные и рекомендуемые заголовки безопасности;
- клавиатурная навигация и режим уменьшенной анимации.

Курсорные 3D-эффекты включаются только на устройствах с точным указателем. При системной настройке `prefers-reduced-motion` анимации и наклоны отключаются автоматически.

Готовый обработчик Google Apps Script находится в папке `backend`. После его публикации укажите полученный адрес в атрибуте `data-endpoint` формы. Пока адрес не задан, сайт открывает заполненное письмо на `technopark@rgsu.net`. Полная инструкция находится в `PRODUCTION.md`.

## Проверка

```bash
npm install
npx playwright install chromium
npm test
```

Статический аудит можно запустить без браузера командой `npm run test:static`.

Перечень последнего пакета доработок находится в `IMPROVEMENTS_25.md`.

Источники и атрибуция фотографий X.Lab перечислены в `ASSET_SOURCES.md`.

Сводка независимого брифинга семи экспертов и принятых решений находится в `EXPERT_BRIEFING_7.md`.

## Автономная версия

Команда `node build-standalone.js` создаёт единый файл `RGSU_SKB_working_site.html`, в который встроены стили, скрипты, шрифты, официальный логотип РГСУ и фотографии кейсов X.Lab. Его можно открыть напрямую без сервера и дополнительных папок.
