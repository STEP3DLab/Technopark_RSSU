# Статичные виды модели

Резервные изображения для ANATOMIA 1.2. Они отрендерены из неизменённого `../models/atlas.glb` в Blender 4.3.2 (Cycles CPU, 32 samples); это не фотографии, не диагностические изображения и не подтверждение работы WebGL/VR. Цвет условный. Для отдельных органов масштаб автоматически адаптирован к кадру.

Исходная геометрия: Z-Anatomy / BodyParts3D, экспорт nqwrc/3d-anatomy. Полные авторство, ссылки и условия: [ASSET_SOURCES](../ASSET_SOURCES.md), [ATTRIBUTION](../models/ATTRIBUTION.md) и [исходное уведомление](../models/License.txt). Применяются лицензии исходных моделей, включая ограничения некоммерческого использования отдельных компонентов; MIT-лицензия кода на изображения не распространяется.

Исходная геометрия, состав структур и ориентация не изменялись. Ракурс камеры, освещение, цвет и кадрирование заданы в `../scripts/render-previews.py`. Распространяемые WebP используют качество 88; загрузка выполняется только при включении резервного режима.
